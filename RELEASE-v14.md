# Тихий ящик — v14, без AI

## Что исправлено
- В обоих листах желаний весь блок со списками и вложенными скрытыми записями помещён в отдельный details. Форма добавления всегда видна. При раскрытии подпись меняется на «Скрыть желания».
- Список договорённостей тоже сворачивается отдельно от формы. Статусы и удаление сохранены.
- Игры перенесены из welcome-блока в компактную кнопку «🐱 Игры» возле идей и настроек. Удалены старые стили большой кнопки.
- 48 локальных вопросов, по 12 на режим: «Котик знает?», «Понять меня», «Мы выбираем», «Наши реакции». В каждом вопросе 4 варианта. Режим следующего раунда выбирается в модальном окне; незаконченный раунд остаётся общим.
- Сохранены отдельные ответы, закрытое раскрытие, угадывания, совпадения, очки и следующий раунд.
- Выровнена ширина карточек «Нашего», убраны принудительная минимальная высота и растяжение с пустым пространством. Формы котика безопасно располагаются вертикально.
- Скрытые сексуальные желания возвращаются явной кнопкой «Открыть партнёру». Новые интимные желания по-прежнему скрыты по умолчанию.

## API и схема
Новых endpoints и таблиц в этой правке нет: /api/games, /api/wishes, /api/agreements и /api/anniversary-ideas уже были в полученном архиве.
Расширена существующая game_rounds: mode_key и mode_label. Миграции ADD COLUMN IF NOT EXISTS в ensureSchema не удаляют данные и сохраняют совместимость старых раундов. Миграции выполнятся приложением при обращении к API после развёртывания.
Сохранены game_answers, wishes, anniversary_ideas и все существующие таблицы.
Все API обслуживает только api/[...path].js.
