# Тихий ящик — v15

## Изменения относительно v14
- Основные вкладки: Ящик → Игры → Свидания → Наше.
- В Ящике три подвкладки: Ящик, Разговор, Домашнее задание. При выборе любой из них родительская вкладка Ящик остаётся активной.
- Игры больше не в topbar и не в модальном окне: это отдельная полноценная вкладка.
- Исправлена причина неверного переключения: API и localStorage теперь ищут незаконченный/последний раунд именно выбранного режима, а не любой общий незаконченный раунд.
- Изменение выбора игры сразу открывает/запускает её раунд. Незаконченные раунды других режимов и отправленные ответы не удаляются. Переключение обратно восстанавливает их. Запоздавший ответ API другого режима не перерисовывает выбранную игру.
- 48 предзаданных вопросов, четыре режима, скрытые до второго ответа результаты и очки сохранены. AI отсутствует.
- Все пять карточек Нашего теперь одной колонкой, на полную одинаковую ширину, строго друг под другом: Выбирает котик, Наши договорённости, Капсула тепла, Лист желаний, Сексуальные желания. Раскрытие details естественно сдвигает следующие карточки вниз.
- Сворачивание списков желаний и договорённостей, privacy и CRUD из v14 сохранены.

## Файлы
Изменены app.js, index.html, extra.css, endpoints/games.js и тесты tests/static.py, tests/fallback.mjs, tests/browser.mjs.
Добавлен этот документ. RELEASE-v14.md оставлен как история предыдущей версии.
Новых endpoints, таблиц и зависимостей нет. Используются существующий /api/games через api/[...path].js и поля mode_key/mode_label, добавленные в v14. Остальные endpoints, Neon, auth, cookies, DATABASE_URL и старые CRUD сохранены.

## Проверки
- node --check app.js, всех endpoints, lib, router и JS-тестов.
- Успешный импорт api/[...path].js.
- Статический аудит IDs, маршрутов, единственной Vercel function и отсутствия AI.
- localStorage: все четыре режима и отдельные незаконченные раунды, восстановление при возврате, раскрытие после двух ответов, очки, обе категории желаний и их приватность/права владельца, договорённости, идеи годовщины.
- Chromium, ширина 1280, 390 и 320 px: новая навигация и подвкладки; переключение всех четырёх режимов; восстановление отправленного ответа; пять карточек строго друг под другом; details; нет pageerror и горизонтального переполнения.
- Новый ZIP проверен unzip -t.

Production, опубликованный сайт и env не менялись. Реальный Neon не вызывался без DATABASE_URL; SQL-код проверен статически, импортом и синтаксически, но не на production-данных. Для публикации разверните содержимое ZIP в прежнем Vercel-проекте, сохранив его env.

Тесты: npm ci; node tests/fallback.mjs; python tests/static.py.
Для tests/browser.mjs нужны playwright, установленный Chromium и статический сервер на порту 8000.
localStorage остаётся локальным fallback одного браузера; между разными устройствами синхронизирует Neon API.
