## Настройки по образцу «Поляны»

Источник вдохновения — присланный проект «полянка»: я прочитал её окно
настроек (`app/polyanka.tsx`, `app/globals.css`) и повторил именно устройство,
а не оформление.

- выдвижная панель справа (`.drawer`) на всю высоту экрана;
- вкладки текстом с подчёркиванием акцента, без «таблеток»;
- содержимое вкладок сразу в панели, с заголовками разделов;
- палитра — три карточки с крупным превью цвета;
- режим — три высокие плитки с иконками;
- порядок разделов — строки с ручкой и стрелками;
- аккаунт — карточка пользователя сверху.

Наши отличия сознательно сохранены: палитра роза/лаванда/дымчато-синяя,
пиксельный шрифт с кириллицей, пиксельные иконки, четыре вкладки под наши
функции, резервная копия — на вкладке «Аккаунт и данные».

Переименований данных нет: состав настроек прежний, изменилась только
подача. Персонализация больше не открывается отдельным окном.
