# Тихий ящик — версия 21

## Что изменилось

- Раннер переименован в **«Любимое село»** и стал бесконечным: в нём больше нет городов, маршрута, километров, таймера, выбора игрока и отдельной кнопки прыжка.
- Забег стартует медленно и непрерывно ускоряется; остаётся одна жизнь, двойной прыжок, небольшой рестарт и три буста: травка, молоко, кожаные ботинки.
- У раннера ровно три препятствия: камень, полное дерево и средний бычок, похожий на коровку. Добавлены локальный `runner-bull.svg` и исправленный `runner-tree.svg` без обрезанной правой стороны.
- Зоны столкновения дерева и бычка привязаны только к видимой плотной части иллюстраций, а не к прозрачным полям SVG.
- Рекорд «Любимого села» хранится по текущей авторизованной личности; рекорд партнёра показывается рядом автоматически.
- В «Крестиках-ноликах» три режима помещаются в одну компактную строку на телефоне. Табло показывает только две цифры: слева всегда счёт вошедшего пользователя, справа — счёт соперника.
- В онлайн-режиме крестиков-ноликов стороны и очередь определяются по авторизованному пользователю, а не ручным выбором.
- Из карточек и вкладок убраны видимые объяснения действий. Вместо них добавлены маленькие `i`-кнопки с сердцем вместо точки: для разделов, подвкладок через активную подсказку и каждой игры.
- В «Двух правдах и одной мечте» убраны пояснения-определения у полей; правила доступны через `i`.
- В заголовке годовщины теперь четыре симметричные эмодзи: две до даты и две после неё.

## Проверки

Выполнены:

```bash
python3 tests/static.py
node tests/fallback.mjs
node tests/browser-v19.mjs
node --check app.js
node --check endpoints/games.js
```

Браузерная проверка на ширинах 1280 и 390 px отдельно подтвердила: полное дерево и бычка на canvas, отсутствие старого маршрутного интерфейса, рост скорости без шестиминутного финиша, одну жизнь, компактную строку режимов, относительный счёт, модальные подсказки и симметрию шапки.
