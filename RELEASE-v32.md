# Тихий ящик 2.2.0 · оформление v32

28 октября 2026. Полное описание — в [README.md](./README.md).

## Что изменилось

- **Настройки вкладками** — «Профиль и вход», «Вид», «Напоминания», «Данные».
  Мышь, стрелки ← →, Home/End; открытие всегда начинается с профиля.
  Резервная копия живёт на вкладке «Данные», тема и порядок вкладок — на «Вид».
- **Новые пиксельные картинки**: иллюстрация шапки главного экрана (два котика у
  почтового ящика, сердечки, трава), та же сцена на экране входа, плюс иконки
  вкладок настроек (профиль, палитра, колокольчик, коробка, замок). Палитра и
  приёмы прежние: целые координаты, `crispEdges`. Генератор — `tools/art-v31.py`.
- **Восстановление домашних заданий и игр**: ответы возвращаются в открытые
  задания с тем же текстом; из игр — свои раунды «Две правды и мечта» и личный
  рекорд забега. Счёт крестиков-ноликов не восстанавливается (зарабатывается
  партиями), закрытые задания не возвращаются (их основа удалена при создании).
- **Поиска по записям нет** — намеренно; `tests/static.py` это охраняет.

## Проверено локально

```
npm test                  # предпочтения, fallback, копии — PASS
python3 tests/static.py   # статика, ссылки, отсутствие поиска — PASS
npm run build             # сборка — PASS
npm run test:ui           # 6 палитр, 320/390/430px, письма — PASS
npm run test:backup-ui    # вкладки настроек, арт, перетаскивание, копии, игры — PASS
node tests/pagination.mjs # длинные письма — PASS
```

Схема БД, набор API-маршрутов и формат хранения не менялись. Новые файлы:
`settings.js`, `assets/ui/{profile,lock,palette,bell,box}.svg`,
`tools/art-v31.py`, `tests/backup-ui.mjs`.

**Не проверялось:** реальные запросы к Neon, GitHub Actions и deployment Vercel —
доступа к ним нет. Локальный режим остаётся демонстрационным.
