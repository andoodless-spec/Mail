# Версия 18 — финальные правки

- Раннер «Сократи километры» переработан в более лаконичный endless-runner в духе игры с динозавром Chrome.
- Дистанция занимает шесть минут активного забега, а скорость плавно увеличивается.
- В игре осталось 3 препятствия (туча, сугроб, высокий мост) и 3 бонуса (билет, письмо, щит).
- Препятствия и бонусы отрисованы SVG-картинками без эмодзи и круглых бейджей.
- Мост сделан выше: для него нужен двойной прыжок.
- Забег ставится на паузу при уходе с вкладки, чтобы не терять прогресс.
- Исправлено отображение поднавигации «Ящика» в других разделах.
- Сокращены описания основных разделов.
