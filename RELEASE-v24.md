# Тихий ящик — версия 24

## «Любимое село»

- Коровка перерисована как более узнаваемая пиксельная корова: читаемая широкая мордочка, прямые уши, короткие рожки и два кадра переставляющихся ног.
- Небо, облака, солнце и холмы теперь тоже собраны из спокойных пиксельных ступеней. Зелёная линия земли остаётся неподвижной — ряби и бегущей травы нет.
- Внутри забега по-прежнему ровно три препятствия-изображения (камень, дерево, бычок) и три буста-изображения (травка, молоко, ботинки), одна игровая жизнь, двойной прыжок и постоянно растущая скорость.
- Видимое табло жизни убрано. Вместо него одна строка: слева тикают время и очки, справа показаны личные рекорды обоих участников.
- `⛶` перенесён вплотную к рестарту. Сначала используется native Fullscreen API / WebKit API; если браузер или встроенный просмотрщик его отклоняет, та же игровая панель надёжно раскрывается во встроенный fullscreen-вид. `Esc` сворачивает такой режим.

## Обычные крестики-нолики

- Поле снова классическое 3 × 3: фигуры остаются в клетках, три в ряд дают победу, а заполненное поле без линии завершает партию ничьёй.
- Локальный fallback, клиент, API и серверная модель используют одну и ту же модель фиксированного поля. Очки начисляются только за настоящую выигрышную линию.

## Карточка партнёра и мобильная вёрстка

- У бейджа «Вместе с …» больше нет отдельной `i`-кнопки. Сдержанная пиксельная `i` с сердечком осталась внутри самой карточки.
- Карточка теперь сначала похожа на короткий профиль: аватар-инициал, имя и список сохранённых пунктов. Поля ввода, добавление, удаление и сохранение скрыты, пока владелец явно не нажмёт «Редактировать».
- После сохранения карточка остаётся открыта, но возвращается в чистый режим просмотра. Возможность добавлять и удалять пользовательские поля сохранена; заметки по-прежнему личные для каждого владельца.
- Кнопка случайной записи «Капсулы тепла» закреплена в нормальном потоке и на телефонах не сдвигается на заголовок.
- Настройки получили симметричную область прокрутки: карточка центрируется по ширине, не выходит за правый край и не создаёт горизонтальную прокрутку на телефонах.

## Проверки

Пройдены:

```bash
python3 tests/static.py
node tests/fallback.mjs
node tests/browser-v19.mjs
```

Браузерный сценарий проверяет 1280 и 390 px, профильный режим просмотра/редактирования, отсутствие горизонтального переполнения у настроек и капсулы, native и CSS-fallback fullscreen раннера, неподвижную землю, оба беговых SVG-кадра, обычные победы и ничьи в крестиках-ноликах.
