# Тихий ящик — версия 25

## Карточка партнёра

- Режим просмотра переработан в более тёплую личную карточку: мягкая обложка с инициалом, счётчик штрихов и плитки только с заполненными деталями.
- Пустые стартовые поля больше не выглядят как список покупок: они остаются доступными в «Редактировать», но в просмотре не показываются до заполнения.
- Все прежние данные `partner_profiles` совместимы: существующие заполненные пункты просто отображаются в новом виде, ничего не удаляется и не переименовывается.

## Игры и подсказки

- Рекорды «Любимого села» стали компактным блоком, как табло в крестиках-ноликах: заголовок «Рекорд», два числа и подписи «мой» / «партнёра».
- В раннере рестарт и полноэкранный режим находятся слева внизу.
- Во всех трёх играх полноэкранный режим теперь находится в едином предсказуемом месте — нижней левой зоне карточки. В крестиках туда же перенесена кнопка новой партии.
- Все кнопки справки теперь выглядят как небольшие полупрозрачные пиксельные сердечки. Они по-прежнему доступны с клавиатуры и содержат понятные aria-подписи.

## Данные существующего сайта

- Новая версия не меняет ключи хранилища игр, профилей, записей, капсул, настроек или рекордов.
- Серверная схема использует только `CREATE TABLE IF NOT EXISTS` и добавочные миграции; она не удаляет таблицы и не очищает строки.
- Чтобы обновлённый сайт увидел все старые ящики, в Vercel нужно оставить **тот же `DATABASE_URL`**, что у текущего сайта. Тогда пользователи, записи, парные коды, игры, рекорды и личные карточки сразу читаются из той же базы.
- Если обновление публикуется на новом домене/новом Vercel-проекте, данные всё равно будут доступны с тем же `DATABASE_URL`, но пользователям понадобится войти заново своим именем и PIN из-за другого cookie-домена.

## Проверки

Пройдены:

```bash
python3 tests/static.py
node tests/fallback.mjs
node tests/browser-v19.mjs
```

Браузерный сценарий проверяет 1280 и 390 px, новый memory-profile, компактное табло рекордов, маленькие полупрозрачные сердце-подсказки, нижние левые utility-зоны всех игр, native/CSS fullscreen и обычные победы/ничьи в крестиках-ноликах.
