# Тихий ящик — версия 26

## Карточка партнёра

- Обложка с именем стала компактнее: счётчик «штрихов» убран, а подпись оставлена короткой — «то, что хочется бережно помнить».
- Обычные плитки воспоминаний больше не раскрашиваются по очереди. Они используют палитру выбранной темы аккаунта.
- В явном режиме «Редактировать» у каждого пункта появился выбор «Акцент»: **По теме**, розовый, лиловый, голубой, зелёный или тёплый. Акцент хранится вместе с конкретной личной заметкой и остаётся приватным для её автора.
- Старые записи `partner_profiles` совместимы: если у пункта ещё нет свойства `accent`, он безопасно показывается как «По теме».

## Игры и подсказки

- В «Любимом селе» время/очки и рекорды теперь находятся в **двух отдельных pill-овальных блоках в одной строке**. Рекорд не выходит из своего контура даже на телефоне.
- Рестарт во всех трёх играх — единый значок `↻`, расположенный рядом с `⛶` в нижней левой utility-зоне. Текстовые кнопки рестарта убраны.
- Пиксельное сердце-подсказка перерисовано симметрично: два полных лепестка, середина и кончик. В обычном состоянии оно стало спокойнее и полупрозрачнее, а при наведении/фокусе остаётся заметным.

## Полная поддержка тем

- Выбранная тема теперь окрашивает не только фон и вкладки, но и карточки, модальные окна, поля ввода, вторичные кнопки, списки, игровые панели и их границы.
- Активные и фокусные элементы используют оттенки текущей темы, а не зафиксированный розовый цвет.

## Обновление существующего Vercel-проекта без потери данных

- Этот релиз предназначен для обновления **текущего** Vercel-проекта. Новый проект и новая база не нужны.
- GitHub для обновления не обязателен: если проект есть только в Vercel, папку можно связать с ним через `npx vercel@latest link` → **Link to existing project**, затем выполнить `npx vercel@latest --prod`.
- Если пустой GitHub-репозиторий уже был подключён с телефона, в архив включена безопасная GitHub Actions-инструкция: один ZIP разворачивается в полный исходный код и становится новым источником Vercel deployment.
- В текущем проекте не меняйте и не удаляйте `DATABASE_URL`: именно эта переменная соединяет новую версию с уже существующими ящиками, парами, PIN-хэшами, записями, капсулами, настройками, личными карточками и игровыми рекордами.
- Схема сервера использует только `CREATE TABLE IF NOT EXISTS` и добавочные миграции; таблицы и строки не удаляются. Изменение акцента памяти хранится в существующем JSON-поле карточки и не требует отдельной разрушительной миграции.
- При обновлении того же Vercel-проекта текущий домен и cookie-сессии сохраняются. Если Vercel всё же выдаёт новый домен, пользователям достаточно войти теми же именем и PIN — данные остаются в базе.

## Проверки

Пройдены:

```bash
node --check app.js
node --check endpoints/partner-profile.js
node --check endpoints/games.js
node --check lib/games.js
python3 tests/static.py
node tests/fallback.mjs
node tests/browser-v19.mjs
```

Браузерный сценарий проверяет ширины 1280 и 390 px, компактную карточку, сохранение выбранного акцента, две runner-pill, полный пиксельный контур сердца, общие нижние иконки рестарта/fullscreen, смену темы для карточки и вторичных контролов, native/CSS fullscreen и обычные победы/ничьи в крестиках-ноликах.
