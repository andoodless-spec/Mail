# Обновить текущий «Тихий ящик» до v28 — только с телефона

Этот путь предназначен для уже подключённого GitHub-репозитория и **того же** Vercel-проекта.

- Не создавайте новый Vercel-проект.
- Не используйте Vercel Drop.
- Не меняйте, не удаляйте и не создавайте `DATABASE_URL`.
- Не нужен Git CLI, компьютер или API-токен.

## Что сделать

1. В текущем GitHub-репозитории загрузите в корень `quiet-mailbox-vercel-v28.zip` и сделайте Commit.
2. Если GitHub открыл Pull Request, обязательно нажмите **Merge pull request → Confirm merge**, чтобы ZIP оказался в `main`.
3. Откройте `.github → workflows → Cunpack-update.yml`, замените его содержимое текстом из `Cunpack-update-v28.yml` и закоммитьте в `main` (PR — тоже merge).
4. GitHub Actions автоматически создаст commit `Обновить Тихий ящик до v28` от `github-actions[bot]`.
5. Дождитесь нового **Production** deployment этого bot-commit в вашем прежнем Vercel-проекте и откройте прежний адрес сайта.

Полная короткая инструкция с проверками и восстановлением после ошибки: [`GITHUB-PHONE-SETUP.md`](./GITHUB-PHONE-SETUP.md).

## Данные остаются прежними

Vercel остаётся подключён к тому же репозиторию и базе. Пока `DATABASE_URL` не меняется, в новой версии остаются существующие ящики, записи, настройки, профили и рекорды.

Если GitHub Action стала красной, не нажимайте Vercel Redeploy для workflow-only commit: он не содержит распакованных исходников. Откройте `GITHUB-PHONE-SETUP.md` и исправьте только указанную там причину.
