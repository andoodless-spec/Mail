# Тихий ящик 2.1.0 · оформление v31

28 октября 2026. Подробное описание — в [README.md](./README.md).

## Что добавлено

- **Резервная копия** в настройках: скачивание JSON и восстановление из файла.
  Собирается и восстанавливается через уже существующие маршруты API — новых
  таблиц и маршрутов нет, формат хранения на сервере не менялся. Файл
  проверяется до применения, показывается состав и предупреждения, и только
  после подтверждения данные добавляются. Ничего не удаляется и не
  перезаписывается молча, повторы по тексту пропускаются.
- **Порядок вкладок перетаскиванием**: главные вкладки, закладки книги, игры и
  свидания. Мышь и палец тянут за ⠿, стрелки ↑↓ остались для клавиатуры.
  Порядок личный; у тех, кто ничего не менял, всё выглядит как раньше.
- **Контраст**: приглушённый текст в светлых темах и подпись на синей кнопке
  доведены до WCAG AA (3.26–4.02 → ≥4.5). Тёмные темы не менялись.

## Ограничения копии (честно показаны в интерфейсе)

- Письма попадают в файл, но не восстанавливаются: они принадлежат текущему
  циклу разговора. Если на момент экспорта письма были закрыты, их текстов в
  файле нет.
- Домашние задания и игры сохраняются в файл, но пока не восстанавливаются.
- В облачном режиме восстановленные записи создаются от текущего аккаунта;
  скрытые записи партнёра не восстанавливаются.

## Проверено локально

```
npm test                 # предпочтения, fallback-модель, резервные копии — PASS
python3 tests/static.py  # статика и ссылки — PASS
npm run build            # сборка — PASS
npm run test:ui          # браузер: 6 палитр, 320/390/430px, письма — PASS
npm run test:backup-ui   # браузер: перетаскивание мышью/пальцем/стрелками,
                         # экспорт, отказ на битом файле, импорт — PASS
node tests/pagination.mjs # длинные письма — PASS
```

Контраст замерен в браузере по вычисленным стилям: приглушённый текст на фоне
4.94, подпись на главной кнопке 4.69 (было 3.72 и 4.69/4.02).

**Не проверялось:** реальные запросы к Neon, GitHub Actions и deployment Vercel —
доступа к ним нет. Локальный режим остаётся демонстрационным и не синхронизируется
между устройствами.
