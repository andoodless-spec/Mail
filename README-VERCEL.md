# Тихий ящик — обновление текущего сайта на Vercel

## Главное: обновляем существующий проект, не создаём новый

Этот архив предназначен для **обновления уже работающего Vercel-проекта**. Не создавайте новый проект и не создавайте новую базу данных.

Новый код сразу подтянет уже созданные ящики, пары, PIN-хэши, записи, капсулы, договорённости, настройки, карточки партнёра, результаты игр и рекорды, если в текущем проекте остаётся его прежняя переменная **`DATABASE_URL`**.

Приложение не очищает базу: схема использует только добавочные `CREATE TABLE IF NOT EXISTS` / `ALTER ... ADD ... IF NOT EXISTS` действия. В этой версии цветовой акцент памяти хранится в существующем JSON-поле карточки, поэтому отдельная миграция или перенос данных не нужны.

> Не удаляйте, не заменяйте и не публикуйте значение `DATABASE_URL`. Если оно уже задано в текущем Vercel-проекте, оставьте его как есть.

## Быстрое обновление текущего Vercel-проекта — только с телефона

1. Скачайте `quiet-mailbox-vercel-v29.zip`.
2. В **том же** подключённом GitHub-репозитории загрузите ZIP в корень и убедитесь, что commit/PR попал в `main`.
3. Обновите только существующий `.github/workflows/Cunpack-update.yml` текстом из `Cunpack-update-v29.yml`.
4. В GitHub → **Actions** вручную запустите «Распаковать Тихий ящик v29» для `main`.
5. Дождитесь commit от `github-actions[bot]`, затем Vercel сам создаст новый Production deployment прежнего проекта.

Не создавайте другой Vercel-проект, не используйте Vercel Drop и не меняйте `DATABASE_URL`.

Подробные короткие телефонные шаги и диагностика Actions: [`GITHUB-PHONE-SETUP.md`](./GITHUB-PHONE-SETUP.md). Полная инструкция первого запуска: [`PUBLISH-ON-VERCEL.md`](./PUBLISH-ON-VERCEL.md).

## Что добавлено в версии 29

- Восстановлен привычный мягкий дизайн исходной версии: нежные фоны и градиенты всех шести личных тем снова различаются и не становятся насыщенной сплошной заливкой.
- Поля, вторичные кнопки и закрытые блоки используют поверхность родительской карточки, поэтому не образуют отдельные белые или бледные прямоугольники.
- В «Любимом селе» сохранено новое числовое HUD: текущий результат и `мой рекорд : рекорд партнёра`; времени и видимых подписей нет.
- Все прежние улучшения v26 сохраняются: личная настройка темы/порядка, приватная карточка партнёра с акцентами, пиксельная коровка, fullscreen fallback и обычные крестики-нолики.

Полный список: [`RELEASE-v29.md`](./RELEASE-v29.md). История: [`RELEASE-v26.md`](./RELEASE-v26.md), [`RELEASE-v25.md`](./RELEASE-v25.md), [`RELEASE-v24.md`](./RELEASE-v24.md), [`RELEASE-v23.md`](./RELEASE-v23.md), [`RELEASE-v22.md`](./RELEASE-v22.md), [`RELEASE-v21.md`](./RELEASE-v21.md).

## Проверки

Перед упаковкой выполняются:

```bash
node --check app.js
node --check endpoints/partner-profile.js
node --check endpoints/games.js
node --check lib/games.js
python3 tests/static.py
node tests/fallback.mjs
node tests/browser-v29.mjs
```

Браузерная проверка запускается на 1280, 390 и 320 px: она проверяет шесть восстановленных мягких тем, отсутствие контрастных вложенных плиток, две числовые runner-pill и обычные победы в крестиках-ноликах.
