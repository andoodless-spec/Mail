# Тихий ящик · 2.3.0

Приложение для пары на Vercel + Neon. Внутренний номер оформления — v33.

## Что нового в 2.4.1 — мелкие правки оформления

- **«Мешочек свиданий»** — из подписи убраны слова «убрать лишние идеи», осталось только название.
- **Синяя светлая тема перекрашена**: вместо серой дымки — спокойная лазурно-серая (`#dde9f2` / `#e9f2f9`, акцент `#507f96`). Тёмная синяя не менялась.
- **Белые блики мягче**: свет сверху на карточках, кнопках, полях и панелях ослаблен примерно вдвое, края больше не выглядят выжженными. Контраст всех шести комбинаций тема × режим — от 4.68.

## Что нового в 2.4.0 — объём, сердечки и порядок вкладок

- **Настоящие сердечки.** Иконка сердца и мини-сердечко в кнопках-подсказках перерисованы по новой сетке 12×10: две доли, выемка сверху и острие снизу — форма читается и в 13 px, и в 100 px.
- **Новая картинка в окне с датой.** Пропали россыпь плюсиков и ромбик: теперь там пиксельный тортик с глазурью, две свечи с пламенем, сердечки и искры. Иллюстрация стоит на мягкой «витрине» с бликом.
- **«Наш уголок» всегда первый** — над «Ящиком». В настройках расположения строка закреплена: ручка неактивна и подписано «всегда первым», остальные вкладки двигаются как раньше.
- **Сердечки-подсказки отодвинуты от рамки** (12 px вместо вплотную), кнопка стала аккуратной пиксельной плашкой с бликом, на телефоне — 10 px.
- **«Убрать идеи, которые совсем не нравятся» → «Мешочек свиданий: убрать лишние идеи».** Раскрытая строка подсвечивается тонкой акцентной полоской, а не широкой заливкой.
- **Объём и переливы во всех темах.** Карточки, кнопки, поля ввода, меню, вкладки и диалоги получили свет сверху, тень снизу и мягкое пятно света в цвете темы. Значения считаются от палитры каждой темы (`color-mix`), поэтому розовая, фиолетовая и синяя одинаково объёмные и днём, и ночью.

### Проверено

`npm test`, `tests/static.py`, `npm run build`, `npm run test:ui`, `npm run test:backup-ui`, `tests/pagination.mjs` — все PASS. Контраст текста в шести комбинациях тема × режим — от 4.62 до 10.03 (порог 4.5). Анимации отключаются при `prefers-reduced-motion`.

## Что нового в 2.3.0 — настройки по образцу «Поляны»

- **Выдвижная панель справа** вместо прежнего центрированного окна: как в «Поляне», на весь экран по высоте, на телефоне — на всю ширину.
- **Подчёркнутые вкладки** вместо «таблеток»: «Оформление», «Расположение», «Напоминания», «Аккаунт и данные». Переключение мышью и с клавиатуры (← →, Home/End), подчёркивание акцентом и `aria-selected`.
- **Содержимое внутри вкладок**, как у «Поляны»: палитра — три карточки с большим превью; режим — три высокие плитки с иконками; порядок вкладок — строки с ручкой; аккаунт — карточка профиля с честной подписью хранилища и резервной копией ниже.
- **Одно окно вместо двух:** персонализация больше не открывается отдельным модальным окном — она живёт на вкладке «Оформление». «Твой вид» в боковой панели открывает сразу оформление, пункт меню ⋯ — сразу «Аккаунт и данные».
- После сохранения вида панель не закрывается, чтобы можно было сразу поправить остальное.

Взято только устройство и композиция (панель, вкладки, карточки превью). Цвета, шрифт, иконки и тексты — наши собственные, из «Тихого ящика».

## Что нового в 2.2.0

- **Настройки вкладками:** «Профиль и вход», «Вид», «Напоминания», «Данные». Переключение мышью, стрелками ← →, Home/End; каждое открытие начинается с профиля. Вкладка «Данные» теперь только про резервную копию, тема и порядок вкладок — на вкладке «Вид».
- **Новая пиксельная иллюстрация** главного экрана и экрана входа (два котика у почтового ящика) и новые иконки для вкладок настроек. Стиль прежний: целые координаты, `crispEdges`, палитра проекта. Генератор — `tools/art-v31.py`, его можно перезапускать.
- **Восстановление домашних заданий и игр** в резервной копии: ответы возвращаются в открытые задания с тем же текстом; из игр — свои раунды «Две правды и мечта» и личный рекорд забега. Счёт крестиков-ноликов не восстанавливается: он зарабатывается партиями, и подделывать его нельзя.
- **Поиска по записям нет и не будет** — это осознанное решение проекта; статическая проверка следит, чтобы поле поиска не появилось случайно.

## Что нового в 2.1.0

- **Резервная копия.** В настройках появились «Скачать копию (JSON)» и «Восстановить из файла». Экспорт собирает данные через уже существующие GET-маршруты, импорт — через существующие POST-маршруты: новых таблиц и новых API нет. Файл сначала проверяется (формат, версия, состав), затем показывается предпросмотр с предупреждениями, и только после подтверждения записи добавляются. Восстановление **только добавляет недостающее**: существующие записи не удаляются и не перезаписываются, повторы по тексту пропускаются.
- **Порядок вкладок перетаскиванием.** В «Персонализации» можно менять порядок главных вкладок, закладок книги, игр и свиданий: тянуть за ⠿ мышью или пальцем; стрелки ↑↓ остаются для клавиатуры. Порядок личный и не меняет вид партнёра. Раньше главные вкладки и закладки книги были закреплены — теперь это настройка с прежними значениями по умолчанию, поэтому у тех, кто ничего не менял, всё выглядит как раньше.
- **Контраст.** Приглушённый текст в светлых темах и подпись на синей кнопке доведены до WCAG AA (было 3.26–4.02, стало ≥4.5). Тёмные темы уже проходили норму и почти не менялись.

Ограничения копии, о которых честно сказано в интерфейсе: письма сохраняются в файл, но не восстанавливаются автоматически (они принадлежат конкретному циклу разговора); закрытое домашнее задание вернуть нельзя — запись, из которой оно создано, удаляется при его создании. Если переписка была закрыта на момент экспорта, текстов писем в файле нет. В облачном режиме восстановленные записи создаются от текущего аккаунта, а скрытые записи партнёра не восстанавливаются.

## Что изменилось

- Три приглушённые личные палитры: розовая, фиолетовая, голубая. У каждой своя тёмная версия; можно следовать настройке устройства. Выбор одного участника не меняет оформление другого.
- Локальный пиксельный шрифт с кириллицей, тематические пиксельные рисунки и розовый котик в favicon/PWA/apple-touch-icon.
- Главная навигация: **Наш уголок / Ящик / Свидания / Игры**. Слева на компьютере, снизу на телефоне.
- «Наш уголок»: большой заголовок с иллюстрацией; все прежние общие блоки. Названия, порядок и видимость настраиваются отдельно для каждого участника. Скрытие блока не удаляет его записи.
- Ящик-книга: **Письма / Разговор / Разобрать отдельно / Договорённости / Капсула тепла**. Категория «Сладость / Гадость» выбирается кнопкой внутри письма; поиска по письмам нет.
- Длинные открытые письма разбиваются на листы с нижними стрелками. Текст остаётся 16px, символы и переносы не теряются, действия показываются на последнем листе соответствующего письма. При открытии окон клавиатура не вызывается автоматически.
- У договорённостей одна форма и один набор данных: блок перемещается между уголком и соответствующей закладкой книги, а не дублируется.
- Личный раздел желаний дополнительно закрыт явным раскрытием. При уходе с экрана он сворачивается.
- После завершения цикла старый текст удаляется не только из состояния, но и из скрытой разметки списка писем.

## Обновление с телефона через GitHub

**Сохраните прежние репозиторий, Vercel-проект и базу Neon.** Не создавайте новую базу и не меняйте существующий `DATABASE_URL`.

1. Загрузите **`quiet-mailbox-v33.zip`** в корень **основной ветки того же репозитория**, к которому подключён текущий Vercel-проект. Не кладите ZIP в папку: workflow ищет `quiet-mailbox*.zip` только в корне и требует ровно один архив.
2. Создайте файл **`.github/workflows/unzip-quiet-mailbox.yml`**, вставьте полный YAML распаковщика и сохраните в основную ветку. Старые распаковщики этого проекта лучше отключить в Actions, чтобы они не запускали старое обновление.
3. Откройте **Actions → Распаковать Тихий ящик и проверить файлы**. Запуск автоматический при изменении ZIP; при необходимости нажмите **Run workflow** и выберите основную ветку.
4. Дождитесь сообщения **«ГОТОВО: все … файлов проверены в ветке …»**. В итогах запуска будет ссылка на проверенный коммит. Проверка читает файлы из заново полученной удалённой ветки, а не только из временной папки GitHub runner.
5. Вкладка **Code**: убедитесь, что появились `redesign.js`, `redesign.css`, `fonts/`, `assets/ui/`, а `package.json` имеет версию `2.0.0`.
6. Дождитесь нового deployment в **существующем** Vercel-проекте. Если бот-коммит не запустил deployment, выполните Redeploy последнего коммита основной ветки.

Распаковщик сам использует основную ветку репозитория — `main`, `master` или другое её имя. Он не делает force-push, не удаляет посторонние файлы, не меняет workflow и не читает секреты Vercel/Neon. Ошибка push или несовпадение хотя бы одного файла завершает запуск ошибкой.

Если GitHub пишет `403` или запрещает push, проверьте **Settings → Actions → General → Workflow permissions → Read and write permissions**. Защищённая ветка может требовать PR — распаковщик её защиту не обходит. При ошибке не считайте обновление установленным только потому, что предыдущий запуск был зелёным.

## Vercel

- Root Directory: корень репозитория после распаковки, не папка с ZIP.
- Framework Preset: Other. В `vercel.json` уже заданы `framework: null`, `npm run build` и Output Directory `dist`.
- Существующие `api/[...path].js`, `endpoints/` и `lib/` остаются в корне и обслуживаются Vercel как серверная часть. Не публикуйте один `dist` на обычный статический хостинг: совместная работа требует API.
- Используйте поддерживаемый Vercel Node.js 22 или 24; для локальной разработки нужен Node.js 20+.
- Не удаляйте и не заменяйте прежний `DATABASE_URL`/интеграцию Neon. Не публикуйте строку подключения в GitHub.
- После установки обновите страницу. На телефоне favicon/PWA может сохраняться в кэше; ссылки на значки обновлены до `v=30`.

## Сохранность функций и ограничения проверки

Файлы серверных маршрутов, авторизации, сессий, схемы БД и бизнес-логики сохранены из переданного исходника. Серверное изменение только в нормализации `lib/preferences.js`: новые настройки используют существующее поле JSONB `users.preferences`, без пересоздания таблиц.

Сохраняются приглашения/PIN, дата открытия писем, раскрытие ответов после двух участников, отдельные желания, капсула, договорённости, годовщина, свидания и прежние игры. Завершение цикла по-прежнему удаляет оставшиеся сладости и гадости; уже созданные отдельные задания сохраняются. Оформление не добавляет шифрования и не является аудитом безопасности исходного приложения.

**Проверено локально, не в вашем облачном проекте:** сборка, синтаксис, согласованность клиентских/серверных настроек, приватность и игры в локальной модели, браузерные сценарии создания/подключения, темы, мобильные ширины 320/390/430px и длинные письма до 3500 символов. Реальные Neon-запросы, GitHub Actions в вашем репозитории и deployment Vercel без доступа к ним не проверялись.

### Локальный просмотр

```bash
npm ci
npm test
python3 tests/static.py
npm run build
npm run dev
```

Сайт будет на `http://localhost:8002`. Этот сервер — только локальное превью: вместо облачного API используется исходная fallback-модель в localStorage. В шапке виден **«Локальный режим»**. Такие данные остаются в одном браузере, не синхронизируются между устройствами и не заменяют Neon. Не используйте локальный режим как защищённое общее хранилище. Если эта пометка появилась на опубликованном сайте, сначала исправьте работу серверного API.

Браузерные проверки (при работающем `npm run dev`):

```bash
npx playwright install chromium
npm run test:ui
npm run test:backup-ui
node tests/pagination.mjs
```

## Ручная проверка после deployment

1. Оба участника входят прежними именами и PIN; старые общие данные видны.
2. Выбор темы и ночного режима меняет только свой аккаунт и сохраняется после перезагрузки.
3. До открытия письма закрыты; открытие по дате/явному подтверждению и завершение цикла работают как раньше.
4. Длинное письмо полностью пролистывается; отдельные ответы не раскрыты, пока не отправлены оба.
5. Проверьте капсулу, скрытые желания, договорённости, свидания и результаты всех игр.
6. В шапке опубликованного сайта **нет** пометки «Локальный режим».
